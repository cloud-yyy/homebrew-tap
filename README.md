# homebrew-tap

Homebrew tap for cloud-yyy tools.

## Install

```
brew install cloud-yyy/tap/ywiki
```

Casks in this repository are published automatically by GoReleaser when a
release is tagged in the source repository. Do not edit them by hand.

| Tool | Source |
| --- | --- |
| ywiki | [cloud-yyy/ywiki](https://github.com/cloud-yyy/ywiki) - Yandex Wiki CLI |
